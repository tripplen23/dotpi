# Interactive subagents

This extension lives in its own repository:

**→ [tripplen23/pi-interactive-subagents-herdr](https://github.com/tripplen23/pi-interactive-subagents-herdr)**

Async, interactive subagents for Pi, running in Herdr panes — spawned in a
labeled pane, steered and resumed by name, sandboxed by default.

Installed as a Pi package (see `settings.json` → `packages`); Pi clones it to
`~/.pi/agent/git/github.com/tripplen23/pi-interactive-subagents-herdr`.
